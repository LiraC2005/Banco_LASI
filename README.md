# Banco_LASI

💰 Sistema Bancário em Python

Um sistema bancário simples desenvolvido em Python no terminal, com autenticação por senha, operações bancárias básicas e registro de histórico com data e horário.

📌 Funcionalidades

🔐 Login com senha
💵 Depósito
💸 Saque
📄 Visualização de extrato
🕒 Registro do horário de cada operação
🚪 Encerramento do sistema

🛠️ Tecnologias Utilizadas

-Python 3
-Biblioteca datetime

📚 Conceitos Aplicados

Estruturas condicionais (if, elif, else)
Estruturas de repetição (while)
Manipulação de listas
Funções de entrada e saída (input e print)
Manipulação de data e hora
Lógica de programação

▶️ Como Executar

Instale o Python 3 em seu computador
Baixe o arquivo .py
Execute no terminal:
python nome_do_arquivo.py

Este projeto foi desenvolvido com fins educacionais para praticar conceitos básicos de programação em Python e simular o funcionamento simples de operações bancárias em terminal.
